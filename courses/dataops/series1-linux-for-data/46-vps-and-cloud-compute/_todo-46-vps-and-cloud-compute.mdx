      WHAT IT IS                 a VPS is a rented Linux machine — Hetzner, DigitalOcean,
                                 Linode, OVH, Vultr. Cloud compute is the same thing from
                                 AWS, GCP or Azure with more knobs and a less predictable
                                 bill. Say the price honestly: a box that runs Postgres
                                 and a nightly pipeline costs less per month than a lunch,
                                 and much of this course turns from reading into practice
                                 once the reader has one.
      RAM BEFORE CORES           a database is a cache with a query engine attached.
                                 Postgres on 2 GB against 8 GB is a different product. The
                                 working set fitting in memory decides, not the CPU.
      THE DISK                   size AND type. NVMe against network storage is an order of
                                 magnitude on the random reads an index does — and the disk
                                 is the thing that fills, which 1 · 07 taught them to watch.
      EGRESS                     the cost line nobody predicts. Compute is metered per hour
                                 and honest; moving a 200 GB extract OUT is charged per
                                 gigabyte. Most VPS providers include a generous allowance
                                 and the big clouds do not, and that one difference decides
                                 more than any benchmark.
      MANAGED OR YOUR OWN        the real fork: RDS or Cloud SQL against Postgres you
                                 installed. Managed costs several times more and gives you
                                 the backups, patching and failover you would otherwise owe
                                 Series 2. State the trade; neither answer is always right.
      THE FIRST TEN MINUTES      an SSH key with password login disabled; a firewall that
                                 exposes ssh and nothing else, because a Postgres port open
                                 to the internet is found by scanners within the hour; the
                                 provider's snapshot checkbox, which is not a substitute
                                 for 1 · 42.
