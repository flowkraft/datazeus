      1. CODE-SERVER             VS Code running as a service on the server, reached at a
                                 URL. Stand it up with the docker run of 1 · 37, put it

                                 plain HTTP with the default password — it is a shell on

      2. SSH FS                  by Kelvin Schoofs (Kelvin.vscode-sshfs). WHY IT IS HERE:
                                 code-server installs extensions from Open VSX rather than
                                 Microsoft's marketplace, and Microsoft's Remote-SSH — the
                                 headline of 38 — is not available there. SSH FS is the
                                 answer: a remote folder over SFTP as a workspace folder,

                                 THE TRADE, HONESTLY: SSH FS gives you the FILES over SFTP.
                                 Remote-SSH gives you the whole environment — terminal,
                                 language servers, extensions — running on the far machine.
                                 For scripts, SQL and config it is exactly right; for a
