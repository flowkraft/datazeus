    ── A BUCKET IS NOT A FOLDER, and this is what people get wrong for months ─
      NO DIRECTORIES             there are keys with slashes in them. "Listing a directory"

      NO PARTIAL WRITES          you replace an object, you do not edit one. No sed -i, no
                                 append, no seek. A pipeline that "updates a file" writes a
                                 new one — which is exactly why data lands here as
                                 immutable Parquet.
      IT IS HTTP                 with a signature, which is why a database can read it
