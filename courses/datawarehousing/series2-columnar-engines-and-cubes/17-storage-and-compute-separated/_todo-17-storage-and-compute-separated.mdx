      SCALE INDEPENDENTLY        a big query gets a big cluster for ten minutes, then

    ── WHAT IT COSTS, AND THIS HALF IS WHY THE EPISODE EXISTS ──────────────
      EVERY READ CROSSES A NETWORK   a latency floor per request. These are throughput
                                 machines and are genuinely poor at point lookups, which
                                 is why nobody serves an application from one.
      CACHING IS THE PERFORMANCE STORY   a local SSD cache on the compute node, so a COLD

                                 "first query is always slow" phenomenon everybody notices
