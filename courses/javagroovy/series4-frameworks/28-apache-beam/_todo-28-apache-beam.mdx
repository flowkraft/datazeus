## See it for yourself

{/* BEAT 3 — NON-NEGOTIABLE. The koan above, or the reason there isn't one.
    If this beat cannot be written, the episode is not ready to be written.

    complete: finish a DoFn so the pipeline produces the right rows. DirectRunner, in
    process, deterministic — no cluster and no clock.

    diagnose: BEAM'S OWN BEST TRAP, and it is this track's kind. A DoFn that caches
    something in a field — a counter, a running total, a lazily-built lookup map. The runner
    is free to instantiate the DoFn many times across many threads and to reuse instances
    between bundles, so the cached value is stale or shared and the output is quietly wrong.
    NOTHING THROWS. A reader who writes Java as if it runs once, in order, on one thread
    produces exactly this — and that misconception is the whole reason the episode is in
    the framework series. */}
