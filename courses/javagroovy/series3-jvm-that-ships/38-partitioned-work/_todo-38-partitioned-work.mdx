      THE SHAPE                    partition by key or range, compute per partition, then COMBINE. Name
                                   it as map and reduce once — not for the buzzword, but because

                                   Series 4 instead of magical.
      FAILURE ONE: SHARED STATE    the groupingBy aggregation from Series 1 - 35, accumulating into a
                                   plain HashMap from several threads, produces A WRONG NUMBER RATHER
                                   THAN AN EXCEPTION. Concurrent collections, or better, a result per
                                   partition and no sharing at all.
      FAILURE TWO: ASSOCIATIVITY   parallel reduction splits and recombines in an order you do not
                                   control, so subtraction or a floating-point sum gives a DIFFERENT
