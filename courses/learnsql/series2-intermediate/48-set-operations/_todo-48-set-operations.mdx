    ── WORKPLACE SKILL — what a working person must be able to do after this episode ──────────
    Stack result sets from two sources (UNION ALL), remove duplicates only on purpose (UNION, and the sort
    it costs), reconcile two lists (EXCEPT both ways, INTERSECT), the column count / type / name rules, and
    ORDER BY on the combined result.
