    ── COVER, IN THIS ORDER ────────────────────────────────────────────────
      GROUPING SETS   the explicit list — you name each grouping you want and the engine
                      reads the source once. START HERE, not with ROLLUP: it is the
                      general form and the other two are shorthands for it.
      ROLLUP(a,b,c)   the hierarchical shorthand: (a,b,c), (a,b), (a), (). Built for
                      natural hierarchies — year/quarter/month, country/region/city.
      CUBE(a,b)       every combination, 2^n of them. Say the cost out loud: CUBE over
                      four columns is sixteen groupings and most reports want three.

    ── THE TRAP, AND IT IS WHY THIS IS NOT A SYNTAX TOUR ───────────────────
    A SUBTOTAL ROW CARRIES NULL IN THE COLUMN IT IS TOTALLING OVER, and that NULL is
    indistinguishable from a real NULL in the data. On a table where region is sometimes
    blank, the report shows two rows that look identical and mean completely different
    things — "the rows with no region" and "all regions". Nothing warns you.

      GROUPING(col)   returns 1 for the superaggregate NULL, 0 otherwise
      GROUPING_ID()   packs several into one number, for ordering and filtering
      the labelling idiom to leave them with:
        CASE WHEN GROUPING(category) = 1 THEN 'All categories' ELSE category END

    This is Series 1 · 45's three-valued logic arriving through a door nobody is watching.
    Make that callback explicit.

    Then ORDER BY, briefly: a result with subtotals interleaved is unreadable unless you
    sort it deliberately, usually by GROUPING_ID and then by the columns.

    ── PORTABILITY, SAID HERE RATHER THAN DEFERRED ─────────────────────────
    PostgreSQL, Oracle, SQL Server and Db2 have all three. MYSQL HAS ONLY
    `GROUP BY ... WITH ROLLUP` — a suffix rather than a function, with no GROUPING SETS
    and no CUBE — and GROUPING() from 8.0. Say it here, because a reader on MySQL will
    otherwise type something that does not parse. Series 4 owns dialects; this is a

    2^n groupings and GROUPING_ID get a line each. MySQL's WITH ROLLUP in one line.
