{/* keep:case-shape:0 */}
<Point title="SQL technique" side="left">

`CASE WHEN … THEN … ELSE … END` is a value chosen row by row: the `WHEN`s are tested from the top, the first true one gives the row its value, and the `ELSE` takes every row left over.

</Point>
{/* /keep */}

<Say who="mnemosyne" pose="pointing-right">

**CASE is SQL's if-then.** It checks each `WHEN` from the top: under 25 is light, under 60 is medium, and `ELSE` catches everything left over. **One new column, worked out row by row.**

</Say>

```sql {3-5}
SELECT "OrderID", "Freight",
       CASE
         WHEN "Freight" < 25 THEN 'light'
         WHEN "Freight" < 60 THEN 'medium'
         ELSE 'heavy'
       END AS "Band"
FROM "Orders"
ORDER BY "OrderID"
LIMIT 6;
```

<Say who="leo" pose="thinking">

So it's an expression, like the ones from the aliases lesson — **it just chooses its value instead of calculating it.**

</Say>

<Point title="SQL technique" side="left">

To sort in an order no column has, `ORDER BY` a CASE that numbers the values: heavy 1, medium 2, light 3.

</Point>
{/* /keep */}

<Say who="mnemosyne" pose="pointing-right">

**The shipping team wants the heaviest freight first.** A plain `ORDER BY "Band"` won't do it — **alphabetically it's heavy, light, medium**, with light stuck in the middle. So write the order you want, as a CASE.

</Say>

```sql {8-9} stampdown
SELECT "Band", count(*) AS "Orders"
FROM (SELECT CASE
               WHEN "Freight" < 25 THEN 'light'
               WHEN "Freight" < 60 THEN 'medium'
               ELSE 'heavy' END AS "Band"
      FROM "Orders") AS t
GROUP BY "Band"
ORDER BY CASE WHEN "Band" = 'heavy' THEN 1
              WHEN "Band" = 'medium' THEN 2 ELSE 3 END;
```

**The query on the left:** before — no subquery, simpler ORDER BY

```sql {8-9}
SELECT CASE
```

```sql {8-9}#good
SELECT "Band", count(*) AS "Orders"

               WHEN "Freight" < 60 THEN 'medium'
               ELSE 'heavy' END AS "Band"
      FROM "Orders") AS t
GROUP BY "Band"
ORDER BY CASE WHEN "Band" = 'heavy' THEN 1
              WHEN "Band" = 'medium' THEN 2 ELSE 3 END;
```

<Beat title="COALESCE is a CASE" />

<Say who="mnemosyne" pose="smiling">

<Point title="SQL technique" side="left">

`SUM(CASE WHEN … THEN 1 ELSE 0 END)` counts the orders of one status, without a `WHERE`. Write one SUM for each status (shipped, cancelled, open) and the counts sit side by side, all in the same `GROUP BY`.

```sql {3-8}
FROM "Orders"
GROUP BY "Channel"
ORDER BY "Orders" DESC;
```
