     COVER: Proxmox Backup Server, which is a separate product and is genuinely the reason

       WHAT IT CHANGES: content-addressed, deduplicated, INCREMENTAL FOREVER backups. After
       the first one, a nightly backup of a 200 GB VM transfers and stores the changed chunks
       only. Deduplication is across all backups and all VMs, so fifty clones of one template
       cost close to one template. The arithmetic is worth showing, because it is the
       difference between keeping four weeks and keeping four days.
       VERIFY JOBS: it re-reads and checksums stored chunks on a schedule and tells you when
       a backup has rotted. That is the "prove it" half, automated, and it is rare.
       PRUNE AND GARBAGE COLLECTION: retention as keep-daily / keep-weekly / keep-monthly,
       and the fact that pruning marks and GC frees — so space does not come back until GC
       runs, which surprises everybody once.
       SINGLE-FILE RESTORE: browse into a backup and pull one file out without restoring the
       whole VM. THE WORKPLACE MOMENT: somebody deleted one configuration file, or one CSV,
       and you are not restoring 200 GB to get it back.
       ENCRYPTION client-side, and where the key lives — because a key stored only on the
