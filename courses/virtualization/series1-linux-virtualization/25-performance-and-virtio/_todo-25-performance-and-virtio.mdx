       VIRTIO IS NOT OPTIONAL   emulated IDE or e1000 hardware is a compatibility crutch and
                                costs a factor, not a percentage. virtio-blk or virtio-scsi
                                for disk, virtio-net for network, and the guest needs the
                                drivers (which every modern Linux has and Windows does not).
       THE DISK CACHE MODE      the setting that matters most and is understood least.
                                `cache=none` sends writes to the disk; `cache=writeback` lets
                                the HOST'S page cache acknowledge them. Writeback is faster
                                and MEANS THE GUEST'S fsync CAN RETURN BEFORE THE DATA IS
                                SAFE — which is Storage for Data, Series 2 · 00's argument,
                                arriving in the one place a data person can actually get it
                                wrong. A database on cache=writeback is a database that can
                                lose committed transactions when the HOST loses power. Say
                                this once, plainly, and make it the takeaway.
       CPU MODEL                host-passthrough against a stable model, and the trade with

                                pins you to matching hardware.
