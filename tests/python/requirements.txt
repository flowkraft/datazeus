# Pinned exactly, on purpose. A koan asserts a specific answer, so a library that changes its
# behaviour under you turns a green koan red for a reason the learner cannot act on. Bump these
# deliberately and re-run every koan, the same way you would bump the DuckDB version in the
# JVM tests' pom.xml.
#
# EVERY LINE HERE IS REQUIRED BY AN EPISODE THAT DECLARES A KOAN. That is the test for adding
# one: find the episode in courses/python/curriculum.yaml, check its `hands_on` contains a
# `koan:` rung, or it does not belong here. Checked against all 34 episodes on 2026-08-24.
#
# NOT HERE, DELIBERATELY:
#   numpy       arrives transitively with pandas. Listed nowhere so it cannot drift out of step
#               with whatever pandas wants — but it IS present, so a koan may import it.
#   matplotlib  the only plotting episode is Series 2 · 40, whose `hands_on` is `jupyter` alone.
#               A plot is judged by eyes, there is no koan, and nothing here needs to draw.
#   scipy       nothing in this track uses it.
# Those two absences are the whole reason this image is ~640MB and the Jupyter one is 5.4GB.
# Somebody who never opens a notebook should not pull five gigabytes to run one koan.
